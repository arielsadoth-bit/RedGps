MANUAL DE USO - REDGPS EVALUADOR TECNICO

1. QUE ES EL SISTEMA

Este sistema sirve para crear examenes tecnicos para candidatos.
El entrevistador genera un enlace, el candidato responde el examen y el resultado se guarda en la base de datos SQLite.

El sistema trabaja localmente en la computadora donde se abre el servidor.


2. COMO ABRIR EL SISTEMA

Paso 1:
Abre la carpeta del proyecto:
C:\Users\Lap145\Desktop\proyecto

Paso 2:
Da doble clic en:
iniciar-sistema.bat

Paso 3:
Abre Chrome y entra a:
http://localhost:8080

Importante:
No cierres la ventana negra del servidor mientras estes usando el sistema.
Si cierras esa ventana, el sitio deja de funcionar.

Cierra la ventana negra que se abrio con iniciar-sistema.bat.

Opcion 2:
Abre Administrador de tareas, busca RedGpsExam.exe y da clic en Finalizar tarea.

Opcion 3:
En PowerShell ejecuta:
Get-Process -Name RedGpsExam,dotnet -ErrorAction SilentlyContinue | Stop-Process -Force

5. COMO CREAR UN EXAMEN

1. Inicia sesion como entrevistador.
2. Entra a Crear examen.
3. Escribe el nombre del examen.
4. Selecciona la cantidad de preguntas, de 1 a 20.
5. Selecciona el tiempo.
6. Marca o desmarca las preguntas que quieres usar en el banco.
7. Puedes usar:
   - Seleccionar todo
   - Deseleccionar todo
8. Da clic en Generar examen aleatorio.
9. Copia el enlace generado.
10. Envia el enlace al candidato por WhatsApp o correo.


6. COMO RESPONDE EL CANDIDATO

El candidato abre el enlace del examen.
El sistema le pide:
- Nombre
- Correo

Despues responde las preguntas.
Cuando termina, da clic en Finalizar examen.

Nota de seguridad:
Si el candidato cambia de pestana, minimiza o sale de la pagina, el examen se finaliza automaticamente con lo que tenga respondido.


7. COMO REVISAR RESPUESTAS

1. Entra a Respuestas.
2. Usa el buscador para encontrar al candidato.
3. Da clic en Ver.
4. Se abre una ventana con solo el examen seleccionado.
5. Revisa respuestas, calificacion y notas.
6. Puedes ajustar:
   - Calificacion final
   - Puntaje por pregunta
   - Nota del entrevistador
7. Da clic en Guardar ajuste.
8. Para salir de la revision, da clic en Cerrar.


8. PREGUNTAS PRACTICAS DE CODIGO

Las preguntas practicas muestran:
- Lenguaje esperado
- Funcion esperada
- Boton Ejecutar pruebas

El candidato puede ejecutar pruebas mientras responde.
El entrevistador tambien puede ejecutar pruebas al revisar la respuesta guardada.


9. COMO CAMBIAR PREGUNTAS

Las preguntas estan en:
Api.cs

Busca:
public static readonly List<ExamQuestion> Questions

Tipos de pregunta:
- closed: pregunta de opcion multiple.
- open: pregunta abierta.
- code: problema practico de programacion.

Despues de cambiar preguntas:
1. Guarda Api.cs.
2. Cierra el sistema.
3. Abre iniciar-sistema.bat otra vez.


10. BASE DE DATOS

La base de datos real esta en:
data\redgps_exam.db

No abras ese archivo con Bloc de notas, Adobe, Photoshop o Illustrator.
Es una base SQLite.

Para abrirla:
Da doble clic en:
abrir-sqlite.bat

Tablas importantes:
- resultados_examenes: examenes finalizados.
- respuestas_examenes: respuestas por pregunta.
- examenes_creados: enlaces generados.


11. EXPORTAR RESULTADOS

Para exportar a CSV:
1. Clic derecho en export-database.ps1.
2. Ejecutar con PowerShell.

16. USAR EL SISTEMA CON DOCKER

Docker sirve para abrir el sistema en un entorno mas controlado.
La base de datos seguira guardandose en:
data\redgps_exam.db

Requisitos:
- Tener Docker Desktop instalado.
- Abrir Docker Desktop antes de ejecutar los comandos.

Para iniciar con Docker:
1. Abre PowerShell en la carpeta del proyecto.
2. Ejecuta:
   docker compose up --build
3. Abre Chrome en:
   http://localhost:8080

Para dejarlo corriendo en segundo plano:
docker compose up --build -d

Para cerrar Docker:
docker compose down

Para ver si esta corriendo:
docker compose ps

Importante:
El archivo docker-compose.yml monta la carpeta data\ dentro del contenedor.
Eso evita que se pierdan resultados al apagar o recrear el contenedor.
